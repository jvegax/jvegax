## 🚀 Products

### [Klubero](https://klubero.com) · `live`

A management platform for sports clubs. It covers members and registrations, season fees paid by card, cash or SEPA direct debit, payouts to each club via Stripe Connect, an online store, push and email notifications, and an AI studio that makes sponsor creatives and social posts.

Real clubs run their day-to-day on it.

`Next.js` `Expo` `NestJS` `Prisma` `PostgreSQL` `Stripe Connect` `Clerk` `BullMQ` `Redis` `OpenAI`

### Tickevo · `in progress`

Ticketing for events where each ticket is an on-chain asset on **Base**. Primary sales are paid in stablecoins. Resale only happens through Tickevo's own marketplace, and that contract splits each price between the seller, the organizer and the platform. Tickevo includes a web dashboard for organizers, a wallet app for attendees and a scanner app for check-in at the door.

`Next.js` `Expo` `NestJS` `Solidity` `Foundry` `OpenZeppelin` `viem` `Crossmint`

## 🤖 AI stack

I use these AI tools every day:

- **Claude Code** is my main pair programmer. Each repo has its own `CLAUDE.md` / `AGENTS.md` rules and custom skills that capture the domain, such as payments, roles, security and the design system. This way the agent works the way the team does.
- **MCP servers** connect the agent to the tools I use, like Stripe and docs.
- **Spec-driven development**: I write features as specs inside the repo first, then build them in small PRs. CI has to be green, and a person reviews every merge.
